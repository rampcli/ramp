# ramp brand

- **Name:** ramp (wordmark always lowercase; "Ramp" is fine at the start of a sentence)
- **Ticker:** $RAMP
- **Pitch:** pump.fun curve math. know when it bonds.
- **Site:** rampcli.dev, opens on the live curve tool (paste a mint) with the playground under it
- **One line:** exact quotes, a dev-buy planner, a launch sim and bundle math for pump.fun style bonding curves.
- **Feel:** a flat fintech trading screen. Dense, left-aligned, big numbers, thin lines, no glow.

## The mark

A concave ramp and a ball: the bonding curve is the ramp, your coin is the ball rolling up it to bond.

| File | Use |
|---|---|
| `assets/icon.png` | App icon, 512px, rounded corners on transparent. README header, lockups, 32px and up |
| `assets/coin.png` | Full bleed icon, 1000x1000. Token image and avatar, reads cropped to a circle |
| `assets/logo.svg` | Flat mark in lime `#B6F23A`, viewBox 0 0 100 100, traced from the icon. Favicons and anything under 32px |
| `assets/logo-mono.svg` | Flat mark in `currentColor` for one-colour uses |
| `assets/banner.png` | Social preview, 1280x640 |

Rules:

- Icon from 32px up, flat mark below 32px.
- The ball sits up and to the right of the ramp foot. Never flip, rotate, stretch or outline it.
- Flat mark in lime, `#EAF5EC`, white or black only. No gradients or shadows on it.
- Clear space around the icon: a quarter of its width.

## Type

- **Archivo** 500, 700, 800 for UI and headings. Headings tight at -0.02em, display type to -0.045em.
- **DM Mono** 400 and 500 for every number, code and CLI output, with tabular figures.
- Wordmark: `ramp` in Archivo 800, tracking -0.03em.

Spacing scale 4, 8, 12, 16, 24, 32, 48, 64. Radius 10px for panels, 6px for buttons and inputs.

## Voice

- Say what it does with a number: "1.4811 SOL to own 5% at launch, fee included."
- Talk like a dev on CT. Short, lowercase taglines, no hype words, no dashes, no emojis.
- Call the sim a model, label example data, add "not financial advice" where it matters.
