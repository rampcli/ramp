# Security

ramp reads data and does math. It has no wallet code, never asks for a key and never signs anything. `ramp ui` listens on 127.0.0.1 unless you pass `--host`.

Found something anyway? Report it privately through a GitHub security advisory:
https://github.com/OWNER/ramp/security/advisories/new

Please keep it out of public issues until there is a fix. Expect a first reply within 7 days.
