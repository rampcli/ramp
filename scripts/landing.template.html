01 / commands

one CLI, ten commands.

The same math in your terminal. Zero dependencies, works offline, every command takes --json.

npx ramp-cli plan --own 5%

state

Price, mcap, curve progress and SOL left until it bonds, from any point on the curve.

ramp state --raised 40

buy / sell

Tokens out, avg price, price impact and mcap after, fee included. Capped where it bonds.

ramp buy 2 --from-raised 40

plan

Dev-buy planner: SOL to own a share, SOL raised to hit an mcap, or what a budget buys along the curve.

ramp plan --own 5%

sim

Seeded Monte Carlo with snipers, a dev buy and random flow. Odds it bonds, sniper and top 10 share.

ramp sim --snipers 10 --seed 42

bundle

N wallets in the launch slot vs the same SOL spread out, wallet by wallet.

ramp bundle --wallets 8 --each 0.5

snipe

Buyers one after another at launch, and how much less the last one gets.

ramp snipe --buyers 5 --each 1

chart

ASCII chart in the terminal, or price vs SOL raised as an SVG.

ramp chart --svg curve.svg

ui

Local dashboard with this playground, the sim and the bundle check. Prints a URL, opens nothing.

ramp ui --port 4178

mcp

Model Context Protocol server over stdio for Claude, Cursor and other agents.

ramp mcp

--rpc --mint

Live mode: derives the bonding curve PDA, reads the account over any RPC, decodes the reserves.

ramp state --rpc URL --mint MINT

03 / agents

ramp speaks MCP.

ramp mcp starts a Model Context Protocol server over stdio. Add it to Claude Desktop, Claude Code or Cursor and ask it to quote, plan or simulate.

claude_desktop_config.jsonjson
{
  "mcpServers": {
    "ramp": {
      "command": "npx",
      "args": ["-y", "ramp-cli", "mcp"]
    }
  }
}
  • curve_statePrice, mcap, progress and SOL left until it bonds. Live with a mint.
  • quote_buyExact result of a buy, fee included.
  • quote_sellExact SOL out for a sell, after the fee.
  • plan_dev_buyOwn X%, hit an mcap, or compare a budget along the curve.
  • simulate_launchSeeded Monte Carlo: odds it bonds and holder concentration.
04 / faq

questions.

are these exactly what pump.fun charges?

It is the constant-product formula with virtual reserves, done in lamports and token base units with BigInt. The defaults are the commonly cited pump.fun launch values. Fees and parameters change, so the fee and every reserve are flags, and live mode reads the real reserves from the account.

is the sim a prediction?

No. It is a model with assumptions you can change (buy sizes, sell share, new wallet share). Use it to compare setups, like 5 snipers vs 20. It does not forecast a specific launch.

do I need an RPC or an API key?

No. The CLI runs offline, and its live mode takes any Solana RPC URL with --rpc. On this site, the curve PDA is derived and the account is decoded in your browser; the read goes through a small proxy that only allows getAccountInfo.

what does the site show for a coin that bonded?

That it bonded, and its DexScreener pair: price, market cap, liquidity and 24h volume. Dollar values next to SOL use the SOL price DexScreener implies, so they are estimates.

does it send transactions?

No. ramp only reads and does math. It never asks for a private key.

why is the npm package called ramp-cli?

ramp is taken on npm. The command it installs is ramp.

other launchpads?

Any constant-product curve with virtual reserves works: pass the parameters as flags or a config file. Live mode only decodes the pump.fun account layout.
